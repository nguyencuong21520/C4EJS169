# TechStore Ecommerce — Starter

Đây là **Bài tập 1 xuyên suốt Lesson 1–13**. Mỗi buổi tiếp tục sửa cùng folder, không tạo website mới.

## Cách dùng
1. Copy folder `starter` thành `techstore-ecommerce`.
2. Mở bằng VS Code và chạy `index.html` với Live Server.
3. Mở `../versions/lesson-01.html` để xem version mẫu của buổi hiện tại.
4. Hoàn thành checkpoint, test rồi commit.

## 13 versions
1. Semantic storefront HTML
2. CSS visual theme
3. Cart badge + product modal
4. Flex/Grid product layout
5. Mobile-first + accessibility + AI review
6. Variables, types, price calculator
7. Stock/promotion conditions and loops
8. Products array
9. Product object models
10. Reusable store functions
11. Search/filter/sort
12. Interactive cart + DOM/events
13. GitHub Pages deployment

## Definition of Done cuối khóa
- Storefront semantic và responsive.
- Product cards render từ array of objects.
- Search, category filter và sort hoạt động.
- Cart add/remove/quantity/total hoạt động.
- Form có label, feedback; keyboard focus rõ.
- Không lỗi Console; README và live GitHub Pages URL.
