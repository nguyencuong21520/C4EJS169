# TechStore Ecommerce — Final Reference

Bản website bán hàng hoàn chỉnh sau 13 buổi. Dùng để giáo viên demo và học sinh đối chiếu sau khi tự làm.

## Tính năng
- Semantic, responsive storefront
- Product catalog render từ array of objects
- Search theo tên/mô tả/tag
- Category filter và sort giá không mutate nguồn
- Stock status và discount price
- Cart drawer: thêm, tăng/giảm, xóa, count và total
- Light/dark theme có aria state
- Newsletter feedback và accessible controls
- Relative paths phù hợp GitHub Pages

## Version history
Mở `../versions/index.html` để xem TechStore từ Version 01 đến Version 13.

## Chạy
Mở `index.html` hoặc dùng Live Server.

## Deploy
Stage đúng file, commit, push repository và bật GitHub Pages. Kiểm tra lại đường dẫn trong URL dạng `username.github.io/repository/`.
