HTML cơ bản — Cheat Sheet

Đủ để tự làm trang “Giới thiệu bản thân” · MindX · Buổi 1 · In ra và để cạnh máy khi code

1. Bộ khung file — gõ ! + Tab trong VS Code

<!DOCTYPE html>                bắt buộc, dòng đầu tiên
<html lang="vi">
<head>                        phần ẨN
  <meta charset="UTF-8">      ← để tiếng Việt không lỗi
  <title>Tên trên tab</title>
</head>
<body>                        phần NHÌN THẤY

  ... nội dung viết ở đây ...

</body>
</html>
Tên file phải là index.html — chữ thường, không dấu, không khoảng trắng.

2. Cách viết một thẻ

<p class="intro">Xin chào!</p>
 ▲   ▲            ▲        ▲
 │   │            │        └ thẻ đóng
 │   │            └ nội dung
 │   └ thuộc tính
 └ tên thẻ (thẻ mở)
  • Mở thẻ nào → phải đóng thẻ đó.
  • Thẻ không cần đóng: <br> <hr> <img> <input>
  • Lồng đúng thứ tự: <p><b>a</b></p> ✔ — <p><b>a</p></b> ✘
  • Ghi chú: <!-- không hiện ra -->

3. Tiêu đề & chữ

ThẻDùng để
<h1>…</h1>Tiêu đề lớn nhất — mỗi trang 1 cái
<h2> <h3>Tiêu đề mục nhỏ hơn (tới h6)
<p>…</p>Một đoạn văn
<br>Xuống dòng
<hr>Đường kẻ ngang
<strong>In đậm
<em>In nghiêng
<mark>Bôi vàng
<small>Chữ nhỏ (ghi chú, bản quyền)

4. Danh sách

<ul>                     ul = dấu chấm tròn
  <li>Chơi game</li>
  <li>Vẽ nhân vật</li>
</ul>

<ol>                     ol = đánh số 1, 2, 3
  <li>Việc làm trước</li>
  <li>Việc làm sau</li>
</ol>
Mỗi dòng là một <li>. Đổi ul ↔ ol là đổi kiểu danh sách.

5. Ảnh & liên kết

Ảnh: src = đường dẫn, alt = mô tả
<img src="anh.jpg" alt="Ảnh của tôi" width="150">

Ảnh trên mạng (không cần tải về)
<img src="https://picsum.photos/150" alt="Ảnh mẫu">

Link sang trang khác, mở tab mới
<a href="https://mindx.edu.vn" target="_blank">MindX</a>

Link gửi email
<a href="mailto:ten@email.com">Gửi mail</a>
Ảnh không hiện → sai src. Tên file phân biệt HOA/thường, và ảnh phải nằm cùng thư mục với file HTML.

6. Bảng

<table border="1" cellpadding="6">
  <tr>                   tr = một HÀNG
    <th>Môn</th>         th = ô tiêu đề (tự đậm)
    <th>Điểm</th>
  </tr>
  <tr>
    <td>Toán</td>        td = ô dữ liệu
    <td>9.0</td>
  </tr>
</table>
Số ô <td> ở mỗi hàng phải bằng số cột, nếu không bảng sẽ méo.

7. Form — ô nhập & nút

<form>
  <label for="ten">Tên:</label><br>
  <input type="text" id="ten" placeholder="Bạn tên gì?">

  <input type="email" id="mail" placeholder="ban@email.com">

  <select id="chu-de">
    <option>Làm quen</option>
    <option>Hỏi bài</option>
  </select>

  <textarea rows="3" cols="35"></textarea>

  <input type="checkbox" id="ok">
  <label for="ok">Đồng ý</label>

  <button type="submit">Gửi</button>
  <button type="reset">Xoá hết</button>
</form>
type của input: text · email · number · password · date · color · checkbox · radio
id của input phải trùng for của label thì bấm vào chữ mới nhảy vào ô.

9. Lỗi hay gặp & cách sửa

Hiện tượngSửa
Tiếng Việt thành ô vuôngThiếu <meta charset="UTF-8">
Chữ dính liền, dàn trang loạnQuên một thẻ đóng ở phía trên
Ảnh hiện icon vỡSai đường dẫn src
Sửa code mà trang không đổiChưa lưu (Ctrl/Cmd + S) hoặc chưa F5
Trang trắng tinhMở nhầm file / nội dung để ngoài <body>

10. Checklist nộp bài

  • File tên index.html, có đủ bộ khung
  • <title> là tên của mình
  • 1 thẻ <h1> — họ tên
  • 1 ảnh <img> có alt
  • 1 đoạn <p> giới thiệu 2–3 câu
  • 1 danh sách <ul> — 3 sở thích
  • 1 bảng <table> — môn học & điểm
  • 1 liên kết <a> chạy được
  • 1 form có ô nhập và nút bấm
  • Mở bằng trình duyệt, không chỗ nào lỗi
