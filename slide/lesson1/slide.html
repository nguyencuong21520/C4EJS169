Bộ ba HTML — CSS — JavaScript

Ví một website như một ngôi nhà thì:

🏠

HTML — Khung nhà

Nội dung & cấu trúc. Đâu là tường, đâu là cửa, đâu là cầu thang. Không có HTML thì không có gì cả.

🎨

CSS — Trang trí

Hình thức. Sơn màu gì, cửa sổ to hay nhỏ, đồ đạc kê ở đâu. Nhà không sơn vẫn ở được, nhưng xấu.

💡

JavaScript — Điện & thiết bị

Hành vi. Bấm công tắc thì đèn sáng, bấm chuông thì cửa mở. Đây là phần "biết phản ứng".

Thứ tự học cũng chính là thứ tự xây nhà: HTML trước → CSS sau → JavaScript cuối.

Cùng một nội dung, khác nhau ở đâu?

Bên trái chỉ có HTML. Bên phải thêm CSS và JavaScript. Vẫn là một nội dung đó.

CHỈ HTML
<h2>Nguyễn Văn An</h2>
<p>Học sinh lớp 8 · Yêu thích game</p>
<button>Kết bạn</button>
HTML + CSS + JS
<div class="card">
  <h2>Nguyễn Văn An</h2>
  <p>Học sinh lớp 8 · Yêu thích game</p>
  <button onclick="ketBan()">Kết bạn</button>
</div>
CSS
.card { background: #ff6b35; color: white; padding: 18px;
  border-radius: 14px; text-align: center; font-family: sans-serif; }
button { background: white; color: #ff6b35; border: 0;
  padding: 9px 20px; border-radius: 99px; cursor: pointer; font-weight: bold; }
JS
function ketBan() {
  document.querySelector("button").innerText = "Đã gửi lời mời ✓";
}
Bấm thử nút "Kết bạn" ở khung bên phải — đó là JavaScript đang làm việc.

Chuẩn bị đồ nghề

1. Trình soạn thảo code

Visual Studio Code (miễn phí, code.visualstudio.com). Cài thêm tiện ích Live Server để lưu file là trang tự tải lại.

2. Trình duyệt

Google Chrome. Nhấn F12 mở DevTools — nơi xem lỗi và thử code trực tiếp.

3. Không cài được gì?

Dùng công cụ online: codepen.io, replit.com hoặc jsfiddle.net. Mở là code được ngay.

4. Quy tắc đặt tên file

Chữ thường, không dấu, không khoảng trắng: index.html, style.css, script.js.

Lưu ý: file trang chủ bắt buộc tên là index.html — đó là file trình duyệt tìm đầu tiên.
PHẦN 1

HTML — Xây khung cho trang web

HyperText Markup Language · Ngôn ngữ đánh dấu, không phải ngôn ngữ lập trình. Nhiệm vụ duy nhất: mô tả nội dung là cái gì.

Thẻ (tag) — viên gạch của HTML

Mỗi phần nội dung được "bọc" trong một cặp thẻ để nói cho trình duyệt biết nó là gì.

CẤU TRÚC MỘT THẺ
<p class="intro">Xin chào!</p>
 │  │      │        │        │
 │  │      │        │        └─ Thẻ đóng
 │  │      │        └────────── Nội dung
 │  │      └─────────────────── Giá trị thuộc tính
 │  └────────────────────────── Tên thuộc tính
 └───────────────────────────── Tên thẻ (thẻ mở)

Ba điều cần nhớ

  • Thẻ mở <p> luôn đi với thẻ đóng </p>.
  • Một vài thẻ không có thẻ đóng (thẻ rỗng): <br>, <hr>, <img>, <input>.
  • Thẻ có thể lồng nhau, nhưng phải đóng đúng thứ tự:
    ✅ <p><b>abc</b></p>   ❌ <p><b>abc</p></b>
Lỗi phổ biến nhất của người mới: quên thẻ đóng. Trang sẽ hiển thị lộn xộn mà không báo lỗi gì cả.

Bộ khung của mọi file HTML

Gõ ! rồi nhấn Tab trong VS Code sẽ tự sinh ra khung này.

index.html
<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="UTF-8">
  <title>Trang đầu tiên của tôi</title>
</head>
<body>

  <h1>Xin chào thế giới!</h1>
  <p>Đây là trang web do tôi tự viết.</p>

</body>
</html>
Thành phầnÝ nghĩa
<!DOCTYPE html>Báo đây là file HTML phiên bản 5 (mới nhất).
<html lang="vi">Bọc toàn bộ trang, ngôn ngữ tiếng Việt.
<head>Thông tin ẩn: tiêu đề tab, bảng mã, liên kết CSS.
<meta charset="UTF-8">Bắt buộc để tiếng Việt không bị lỗi font.
<title>Chữ hiện trên tab trình duyệt.
<body>Mọi thứ người dùng nhìn thấy nằm ở đây.

Tiêu đề & đoạn văn

Có 6 cấp tiêu đề, từ h1 (to nhất) đến h6. Mỗi trang chỉ nên có một thẻ h1.

HTML
<h1>Tiêu đề cấp 1</h1>
<h2>Tiêu đề cấp 2</h2>
<h3>Tiêu đề cấp 3</h3>

<p>Đây là một đoạn văn bình thường. Dù bạn
   xuống dòng trong code, trình duyệt vẫn gộp
   lại thành một dòng liền mạch.</p>

<p>Muốn xuống dòng thật <br> thì dùng thẻ br.</p>

<hr>
<p>Thẻ hr vẽ một đường kẻ ngang.</p>
Quan trọng: đừng dùng h1 chỉ vì muốn chữ to — hãy dùng đúng cấp bậc nội dung, việc phóng to là nhiệm vụ của CSS.

Định dạng chữ

HTML
<p>Chữ <b>in đậm</b> và <strong>rất quan trọng</strong></p>
<p>Chữ <i>in nghiêng</i> và <em>nhấn mạnh</em></p>
<p>Chữ <u>gạch chân</u>, <s>gạch ngang</s>, <mark>bôi vàng</mark></p>
<p>Công thức: H<sub>2</sub>O và 2<sup>10</sup> = 1024</p>
<p>Trích dẫn: <q>Học lập trình rất vui</q></p>
<p>Đoạn code: <code>console.log("hi")</code></p>
<small>Chữ nhỏ dùng cho ghi chú.</small>
b vs strong? Nhìn giống hệt nhau, nhưng strong mang ý nghĩa "nội dung này quan trọng" — giúp Google và phần mềm đọc màn hình cho người khiếm thị hiểu đúng. Ưu tiên strong và em.

Liên kết & hình ảnh

Hai thẻ làm nên "web": <a> nối các trang với nhau, <img> mang hình ảnh vào trang.

HTML
<!-- Liên kết ra trang khác, mở ở tab mới -->
<a href="https://mindx.edu.vn" target="_blank">Trang MindX</a>

<!-- Liên kết tới file khác trong cùng thư mục -->
<a href="lienhe.html">Trang liên hệ</a>

<!-- Gọi điện / gửi mail -->
<a href="mailto:hocsinh@mindx.vn">Gửi email</a>

<!-- Hình ảnh: src = đường dẫn, alt = mô tả khi ảnh lỗi -->
<img src="https://picsum.photos/200/120"
     alt="Ảnh minh hoạ" width="200">

<!-- Ảnh bọc trong link: bấm vào ảnh để chuyển trang -->
<a href="https://mindx.edu.vn">
  <img src="https://picsum.photos/120/80" alt="Bấm vào tôi">
</a>
Thuộc tính alt là bắt buộc: khi ảnh không tải được, người dùng vẫn biết đó là ảnh gì; người khiếm thị cũng nghe được mô tả này.

Bảng dữ liệu

HTML
<table border="1" cellpadding="8">
  <thead>
    <tr>
      <th>Môn</th>
      <th>Điểm</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Toán</td>
      <td>9.0</td>
    </tr>
    <tr>
      <td>Lập trình</td>
      <td>10</td>
    </tr>
  </tbody>
</table>
tr = một hàng · th = ô tiêu đề (tự in đậm) · td = ô dữ liệu. Chỉ dùng bảng cho dữ liệu dạng bảng, đừng dùng bảng để dàn trang — việc đó là của CSS.

Thẻ gom nhóm & thẻ ngữ nghĩa

div & span — hai thẻ "vô hình"

  • <div>: cái hộp, chiếm trọn chiều ngang, dùng để gom nhóm các phần lớn.
  • <span>: bọc một mẩu chữ nhỏ nằm trong dòng.

Chúng không có hình dạng gì cả — nhưng là "tay cầm" để CSS và JS bám vào.

Thẻ ngữ nghĩa (semantic)

Thay vì div cho mọi thứ, HTML5 cho ta những thẻ có tên nói lên vai trò:

headernavmain sectionarticleasidefooter
HTML
<header>
  <h2>Blog của An</h2>
  <nav>
    <a href="#">Trang chủ</a> |
    <a href="#">Giới thiệu</a>
  </nav>
</header>

<main>
  <article>
    <h3>Bài viết đầu tiên</h3>
    <p>Hôm nay tôi học <span class="hot">HTML</span>.</p>
  </article>
</main>

<footer>© 2026 - An</footer>
CSS
header { background: #ff6b35; color: #fff; padding: 10px; }
header a { color: #fff; }
main { padding: 10px 0; }
.hot { color: #e63946; font-weight: bold; }
footer { border-top: 1px solid #ccc; color: #888; font-size: 13px; padding-top: 8px; }

🛠️ Thực hành 1 — Trang giới thiệu bản thân

Yêu cầu (10 phút)

  1. Tạo file index.html với bộ khung chuẩn.
  2. Thẻ h1: tên của bạn.
  3. Một ảnh đại diện bằng img (dùng https://picsum.photos/200 nếu chưa có ảnh).
  4. Một đoạn p giới thiệu 2–3 câu về bản thân.
  5. Một danh sách ul: 3 sở thích.
  6. Một bảng table: 3 môn học yêu thích và điểm số.
  7. Một liên kết a tới trang web bạn thích.

Gợi ý khi bị kẹt

  • Chưa hiện gì? Kiểm tra đã lưu file (Ctrl+S) và mở đúng file chưa.
  • Tiếng Việt bị lỗi ô vuông? Thiếu <meta charset="UTF-8">.
  • Ảnh không hiện? Sai đường dẫn src — thử copy link ảnh từ trình duyệt.
  • Chữ dính liền kỳ lạ? Có thể quên một thẻ đóng ở phía trên.
Mẹo: viết xong mỗi phần thì lưu và F5 xem kết quả ngay, đừng viết một mạch 50 dòng rồi mới chạy.
PHẦN 2

CSS — Khoác áo đẹp cho trang web

Cascading Style Sheets · Quyết định mọi thứ trông như thế nào: màu sắc, phông chữ, kích thước, vị trí, hiệu ứng.

3 cách đưa CSS vào trang

1. Inline — trong thẻ

<p style="color: red">Chữ đỏ</p>

Nhanh nhưng rối, chỉ dùng để thử nhanh.

2. Internal — trong <head>

<head>
  <style>
    p { color: red; }
  </style>
</head>

Tiện khi làm bài tập nhỏ, một file duy nhất.

3. External — file riêng ⭐

<head>
  <link rel="stylesheet"
        href="style.css">
</head>

Cách chuyên nghiệp. Một file CSS dùng chung cho nhiều trang HTML.

Nếu cùng một thuộc tính bị khai báo nhiều nơi: inline thắng internal, internal/external cái nào viết sau thì thắng. Đó là chữ "Cascading" — đổ tầng.

Cú pháp CSS

CẤU TRÚC MỘT QUY TẮC
h1 {
  color: orange;
  font-size: 32px;
}
│   │      │
│   │      └── Giá trị (value)
│   └───────── Thuộc tính (property)
└───────────── Bộ chọn (selector): áp dụng cho ai

Ba dấu phải nhớ

  • { } bọc toàn bộ khai báo.
  • : ngăn giữa thuộc tính và giá trị.
  • ; kết thúc mỗi dòng khai báo.
Quên dấu ; là lỗi số 1 khi học CSS: dòng đó và thường cả dòng sau sẽ không có tác dụng, mà trình duyệt không báo lỗi.

Ghi chú trong CSS

/* Đây là ghi chú, trình duyệt bỏ qua */

Bộ chọn (selector) — chọn đúng thứ cần tô

HTML
<h2>Chọn theo tên thẻ</h2>
<p>Đoạn văn thường</p>
<p class="noibat">Đoạn văn có class</p>
<p class="noibat">Class dùng lại được nhiều lần</p>
<p id="dacbiet">Đoạn văn có id (duy nhất)</p>
<div><p>Đoạn văn nằm trong div</p></div>
CSS
/* Tên thẻ: mọi thẻ p */
p { color: #555; }

/* .class - dùng cho NHIỀU phần tử */
.noibat { color: #ff6b35; font-weight: bold; }

/* #id - CHỈ MỘT phần tử duy nhất trên trang */
#dacbiet { background: #ffe8d6; padding: 6px; }

/* Con cháu: thẻ p nằm bên trong div */
div p { border-left: 4px solid #4cc9f0; padding-left: 8px; }

/* Nhiều selector cùng lúc */
h2, .noibat { font-family: Georgia, serif; }
Khi nào dùng class, khi nào dùng id? Gần như luôn dùng class. id chỉ dành cho thứ duy nhất trên trang (và hay dùng cho JavaScript).

Màu sắc & nền

HTML
<p class="c1">Màu theo tên: tomato</p>
<p class="c2">Màu HEX: #4cc9f0</p>
<p class="c3">Màu RGB: rgb(61, 220, 151)</p>
<p class="c4">Nền mờ: rgba(255,0,0,0.15)</p>
<div class="gradient">Nền chuyển sắc (gradient)</div>
CSS
.c1 { color: tomato; }
.c2 { color: #4cc9f0; }
.c3 { color: rgb(61, 220, 151); }
.c4 { background-color: rgba(255, 0, 0, 0.15); padding: 6px; }

.gradient {
  background: linear-gradient(90deg, #ff6b35, #ffd166);
  color: white;
  padding: 16px;
  border-radius: 10px;
  text-align: center;
  font-weight: bold;
}
Mã HEX đọc thế nào? #RRGGBB — hai ký tự đỏ, hai ký tự xanh lá, hai ký tự xanh dương, từ 00 (không có) đến ff (tối đa). Lấy mã màu nhanh tại coolors.co hoặc bảng màu trong VS Code.

Chữ & phông chữ

HTML
<h3 class="tieude">Tiêu đề được canh giữa</h3>
<p class="doan">Đoạn văn này được chỉnh cỡ chữ, khoảng cách dòng,
giãn chữ và đổi phông chữ cho dễ đọc hơn hẳn.</p>
<p class="hoa">viết hoa toàn bộ</p>
CSS
.tieude {
  text-align: center;        /* left | center | right */
  color: #ff6b35;
  text-decoration: underline;
}
.doan {
  font-family: Georgia, "Times New Roman", serif;
  font-size: 17px;           /* px | em | rem | % */
  line-height: 1.8;          /* khoảng cách giữa các dòng */
  letter-spacing: 0.5px;     /* giãn chữ */
  font-style: italic;
}
.hoa {
  text-transform: uppercase; /* uppercase | lowercase | capitalize */
  font-weight: bold;
  letter-spacing: 2px;
}

Box model — mọi thứ đều là cái hộp

Đây là khái niệm quan trọng nhất của CSS. Mỗi phần tử gồm 4 lớp bao quanh nhau.

margin — khoảng cách với hộp khác
border — viền
padding — đệm bên trong
content — nội dung
LớpLà gì
contentChữ hoặc ảnh thật sự bên trong.
paddingĐệm giữa nội dung và viền. Làm nội dung "thở".
borderĐường viền bao quanh.
marginKhoảng trống bên ngoài, đẩy các hộp ra xa nhau.
Mẹo phân biệt: padding làm hộp phình to, margin làm hộp đứng xa hộp khác.

Box model trong thực tế

HTML
<div class="hop tho">Không padding, không margin</div>
<div class="hop dep">Có padding + margin + border + bo góc</div>
CSS
.hop { background: #dff6ff; border: 2px solid #4cc9f0; }

.tho { padding: 0; margin: 0; }

.dep {
  padding: 16px;            /* 4 cạnh đều 16px */
  margin: 20px 0;           /* trên-dưới 20px, trái-phải 0 */
  border: 3px dashed #ff6b35;
  border-radius: 12px;      /* bo góc */
  box-shadow: 0 6px 16px rgba(0, 0, 0, .15);
  width: 300px;
}

/* Viết riêng từng cạnh khi cần */
/* padding: 10px 20px 10px 20px  =>  trên phải dưới trái */
Mẹo vàng: thêm * { box-sizing: border-box; } ở đầu file CSS — khi đó width đã bao gồm padding và border, tính toán dễ hơn rất nhiều.

Sắp xếp với Flexbox

Cách hiện đại và dễ nhất để xếp các phần tử thành hàng/cột, canh giữa mọi thứ.

HTML
<div class="hang">
  <div class="o">1</div>
  <div class="o">2</div>
  <div class="o">3</div>
</div>

<div class="giua">Căn giữa hoàn hảo</div>
CSS
.hang {
  display: flex;                  /* bật chế độ flex */
  gap: 12px;                      /* khoảng cách giữa các ô */
  justify-content: space-between; /* dàn theo chiều ngang */
}
.o {
  flex: 1;                        /* chia đều chiều rộng */
  background: #ff6b35; color: #fff;
  padding: 18px; text-align: center; border-radius: 8px;
}
.giua {
  display: flex;
  justify-content: center;  /* căn giữa ngang */
  align-items: center;      /* căn giữa dọc */
  height: 90px;
  margin-top: 14px;
  background: #4cc9f0; color: #fff; border-radius: 8px;
}
Nhớ 3 dòng này là làm được 80% bố cục: display:flex · justify-content (ngang) · align-items (dọc).

PHẦN 3

JavaScript — Cho trang web biết suy nghĩ

Đây mới là ngôn ngữ lập trình thật sự: có biến, có điều kiện, có vòng lặp. Nó khiến trang web phản ứng lại với người dùng.

JavaScript làm được gì?

🖱️

Phản ứng

Bấm nút, gõ phím, cuộn chuột → trang làm gì đó.

🔄

Thay đổi trang

Đổi chữ, đổi màu, ẩn/hiện, thêm phần tử mới.

🧮

Tính toán

Máy tính, tính điểm, kiểm tra mật khẩu hợp lệ.

🌐

Lấy dữ liệu

Tải thời tiết, tin tức… từ server mà không tải lại trang.

Nhúng JavaScript vào trang

CÁCH 1 — VIẾT THẲNG TRONG HTML
<body>
  <h1>Trang của tôi</h1>

  <!-- Đặt script ở CUỐI body -->
  <script>
    console.log("Xin chào!");
  </script>
</body>
CÁCH 2 — FILE RIÊNG (NÊN DÙNG)
<body>
  <h1>Trang của tôi</h1>

  <script src="script.js"></script>
</body>
Luôn đặt thẻ <script> ở cuối <body>. Nếu đặt trên <head>, JS chạy khi HTML chưa vẽ xong → không tìm thấy phần tử nào cả.

console.log — người bạn thân nhất

In ra bảng điều khiển (Console) để xem code đang chạy tới đâu, giá trị đang là bao nhiêu.

script.js
console.log("Xin chào MindX!");
console.log(2 + 3);
console.log("Tổng là:", 2 + 3);

let ten = "An";
console.log("Chào " + ten);

Xem kết quả ở đâu?

  1. Mở trang web trong Chrome.
  2. Nhấn F12 (hoặc chuột phải → Inspect).
  3. Chọn tab Console.
Console cũng là lời nhắc lỗi: khi code sai, dòng chữ đỏ ở đây cho biết sai ở file nào, dòng bao nhiêu. Luôn mở Console khi lập trình!

Biến & kiểu dữ liệu

// let: giá trị CÓ THỂ thay đổi

function xepLoai() {
  // Lấy giá trị người dùng nhập, đổi sang số
  let diem = Number(document.getElementById("diem").value);

Vòng lặp: làm việc lặp đi lặp lại

HTML
<div id="out"></div>
JS
let ketQua = "";

// for: lặp 5 lần, i chạy từ 1 đến 5
for (let i = 1; i <= 5; i++) {
  ketQua += "Dòng số " + i + "<br>";
}

// Lặp qua từng phần tử của mảng
let monHoc = ["Toán", "Văn", "Lập trình"];
for (let mon of monHoc) {
  ketQua += "📚 " + mon + "<br>";
}

// Bảng cửu chương 3
for (let i = 1; i <= 5; i++) {
  ketQua += "3 x " + i + " = " + (3 * i) + "<br>";
}

document.getElementById("out").innerHTML = ketQua;
i++ nghĩa là "tăng i thêm 1". Thiếu nó → vòng lặp chạy mãi mãi và trình duyệt bị treo.

Ví dụ vui: đổi màu nền ngẫu nhiên

let mauList = ["#ff6b35", "#4cc9f0", "#3ddc97", "#ffd166", "#b085ff"];

function doiMau() {
  // Math.random() cho số ngẫu nhiên từ 0 đến dưới 1
  let viTri = Math.floor(Math.random() * mauList.length);
  let mau = mauList[viTri];

  document.body.style.background = mau;

function reset() {
  document.body.style.background = "white";
  document.getElementById("ma").innerText = "";
}

Kiểm tra nhanh — bấm vào câu hỏi để xem đáp án

1. Thẻ nào bọc phần nội dung mà người dùng nhìn thấy? (bấm để lật)
→ <body>. Còn <head> chứa thông tin ẩn.
2. Muốn nhiều phần tử dùng chung một kiểu CSS thì nên dùng class hay id?
→ class. id phải là duy nhất trên toàn trang.
3. Khoảng trắng bên trong viền của một hộp gọi là gì?
→ padding. Bên ngoài viền là margin.
4. let x = 5 và const x = 5 khác nhau ra sao?
→ let cho phép gán lại giá trị sau này, const thì không.
5. Câu lệnh nào lấy ra phần tử có id="tieude"?
→ document.getElementById("tieude") hoặc document.querySelector("#tieude").
6. Vì sao nên đặt thẻ <script> ở cuối <body>?
→ Để HTML được vẽ xong trước, JS mới tìm thấy các phần tử cần thao tác.
