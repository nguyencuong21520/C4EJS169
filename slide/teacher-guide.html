Cách dùng live demo

Trước khi chạy

  1. Cho học sinh dự đoán kết quả.
  2. Đọc HTML/CSS/JS theo dòng dữ liệu.
  3. Chỉ ra một dòng sẽ thay đổi.

Sau khi chạy

  1. Thử normal case.
  2. Thử rỗng, boundary và input sai.
  3. Mở DevTools khi hành vi khác dự đoán.

Chạy và xuất tài liệu

Cách nhanh: mở slide/index.html trực tiếp. Với live development, mở workspace trong VS Code và dùng Live Server. Để xuất PDF, mở một lesson → Print → Landscape; CSS print sẽ hiển thị toàn bộ slide, mỗi slide một trang.

Kiểm tra trước buổi học: Internet nếu demo dùng link ngoài, zoom 100%, chế độ toàn màn hình, âm thanh/video nếu có, và thử quiz một lượt.

Nguyên tắc dùng AI trong lớp

  1. Prompt phải có context, constraint và acceptance criteria.
  2. Học sinh phải giải thích được code trước khi dùng.
  3. Luôn chạy, test edge case, xem Console và kiểm tra keyboard.
  4. Không đưa secret, dữ liệu cá nhân hoặc code riêng tư vào prompt.
  5. AI hỗ trợ review; trách nhiệm cuối vẫn thuộc người viết.
